# Feature Landscape: International Backstory & Credibility

**Domain:** B2B brand positioning for automotive broker
**Researched:** 2026-04-03

## Table Stakes

Features/elements that dealers expect. Missing = not credible.

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| Real person name + photo | S74: "dealer del Sud compra una persona" | Low | Photo shoot or good headshot needed |
| Phone number (fixed) | Tangibility signal | Low | Already have VoIP 0972 536 918 |
| Consistent story across channels | Any incoherence = "truffatore" | Medium | Requires cross-channel audit |
| Process explanation (step-by-step) | All credible mandatari use this | Low | 4-5 numbered steps |
| Zero-upfront-fee messaging | Differentiator vs ALL competitors | Low | Already in place |
| Google Business listing | First thing dealers check | Low | Already exists, needs description update |

## Differentiators

Features that set ARGOS apart. Not expected, but valued.

| Feature | Value Proposition | Complexity | Notes |
|---------|-------------------|------------|-------|
| "73 portals / 19 countries" claim | No competitor can match this number | Low | Real, verifiable |
| "4 independent analyses" protocol | Technical credibility | Low | CoVe v4 does exactly this |
| LinkedIn thought leadership | No Italian mandatario does this | Medium | 2-3 posts/week for 4 weeks |
| Prepared answers for hard questions | Confidence in dealer conversations | Low | Document ready |
| Vehicle-first outreach (no pitch) | Competitors pitch first, vehicle second | Low | Already in communication rules |

## Anti-Features

Features to explicitly NOT build.

| Anti-Feature | Why Avoid | What to Do Instead |
|--------------|-----------|-------------------|
| Fake Amsterdam HQ | Verifiable lie, catastrophic if found | Remove, use real person + Italian contact |
| "Est. 2024" date | Domain registered 2026, easily debunked | Remove entirely |
| DAT/DEKRA badges | Not operationally active | Replace with "Analisi storico veicolo" |
| Fake team / "our analysts" | Dealer discovers it's one person = trust destroyed | Always say "I", never "we/our team" |
| Backdated LinkedIn posts | Technically impossible, any trick detectable | Forward-looking retrospective posts instead |
| Purchased Trustpilot reviews | Trustpilot anti-fraud = page ban | Earn from real interactions |
| Invented EU dealer references | If asked for names, game over | Offer dossier as proof of competence |

## Feature Dependencies

```
Landing cleanup --> Narrative foundation --> Outreach resume
LinkedIn posts --> Time (weeks) --> Authority perception
Real dealer interactions --> Trustpilot reviews --> Social proof
```

## MVP Recommendation

Prioritize:
1. Remove false claims from landing (P0, blocks everything)
2. Rewrite "Chi siamo" with verifiable facts
3. Update Google Business description
4. Prepare FAQ document for hard questions

Defer:
- LinkedIn strategy: valuable but not blocking outreach
- Trustpilot: depends on real interactions, cannot be rushed
