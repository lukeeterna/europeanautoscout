  <action>
Create tools/validation/test_recalls_warranty.py. Standalone script (no imports from src/ or tools/scrapers/).

Test 4 tools for each VIN in test_vins.json:

**TOOL D: car-recalls.eu**
For each VIN:
- GET https://car-recalls.eu/en/vin/{VIN}
- Headers: User-Agent "Mozilla/5.0...", Accept "text/html"
- Timeout: 15s
- Check response:
  - If 200 + HTML contains "recall": extract recall count, campaign IDs, dates
  - If 200 + "no recalls found": document as CLEAN result
  - If 403/JS-wall (response < 1000 chars or no <html>): document as BLOCKED
- Also try: GET https://car-recalls.eu/api/v1/vin/{VIN} (check if JSON API exists)

**TOOL E: KBA recall database (kba-online.de)**
For each VIN:
- GET https://www.kba-online.de/rrdb/buerger to get the form
- Extract form action URL and field names from HTML (look for <form> and <input> elements)
- POST the form with the VIN in whatever field maps to "FIN/VIN/Fahrzeugidentnummer"
- Timeout: 20s
- If 200: look for recall table in response HTML
- If CAPTCHA (response contains "captcha" or "recaptcha"): document as BLOCKED_CAPTCHA
- If 403: document as BLOCKED_403

**TOOL F: BMW warranty portal**
For each BMW VIN only (skip Porsche):
- Attempt 1: GET https://www.bmw.de/content/dam/bmw/marketDE/bmw_de/navigation/warranties/warranty-check.html
- Attempt 2: GET https://www.bmwusa.com/content/dam/bmwusa/common/warranties/warranty-check.html
- Attempt 3: Search for BMW warranty check API by looking at: https://api.bmw.com/warranty/v1/check (speculative)
- Document: does any BMW URL return a usable form or API? Is there a login wall?
- This is expected to require login — document the exact barrier

**TOOL G: RDW open data NL**
NOT VIN-based — plate-based:
- Test with a synthetic NL plate: "24-ZNT-2" (random format test)
- GET https://opendata.rdw.nl/resource/m9d7-ebf2.json?kenteken=24ZNT2 (no dashes for API)
- Timeout: 10s
- If 200: document fields returned (expected: kenteken, voertuigsoort, merk, km_teller_oordeel, etc.)
- If works: document that VIN→plate lookup is still unsolved (we'd need to find NL plate separately)
- Document: RDW works but requires NL plate number, not VIN. For our DE-sourced vehicles, this tool has limited applicability unless we find the plate from the AS24 listing.

For each tool, record:

```json
}
```

Print to stdout: "[TOOL] VIN {vin[:8]}...: HTTP {status} — {pass/blocked}"
Use time.sleep(2) between requests. Write all results to tools/validation/results/recalls_warranty_results.json.
