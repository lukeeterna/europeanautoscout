  <action>
Create tools/validation/test_vin_decode.py. The script tests two tools for each VIN in test_vins.json and writes structured results.

Structure the script with test functions — one per tool:

**TOOL A: freevindecoder.eu**
Try endpoint 1 (JSON API): GET https://www.freevindecoder.eu/api?vin={VIN}&apikey=0
- Headers: User-Agent "Mozilla/5.0...", Accept "application/json"
- Timeout: 15s
- If 200: parse JSON, extract all fields present
- If 403/404/other: try endpoint 2

Try endpoint 2 (HTML scrape): GET https://www.freevindecoder.eu/?vin={VIN}
- Extract table data: look for rows with "Manufacturer", "Model", "Model Year", "Engine", "Fuel type", "Country"
- Use regex: r'<td[^>]*>\s*([A-Za-z\s]+)\s*</td>\s*<td[^>]*>\s*([^<]+)\s*</td>'
- Also try: BeautifulSoup if available, else raw regex

Record per VIN:
```json
{
  "tool": "freevindecoder",
  "vin": "...",
  "http_status": 200,
  "fields_returned": ["make", "model", "year", "engine", "fuel"],
  "sample_value": {"make": "BMW", "model": "X3", ...},
  "claims_verified": true/false,
  "integration_path": "GET /api?vin=VIN&apikey=0",
  "cost": "€0",
  "notes": "..."
}
```

**TOOL B: NHTSA API**
VIN decode endpoint: GET https://vpic.nhtsa.dot.gov/api/vehicles/decodevinvalues/{VIN}?format=json
- Timeout: 15s
- Parse "Results" array — find non-empty fields: Make, Model, ModelYear, FuelTypePrimary, EngineModel, BodyClass
- Recall lookup (by make/model/year, not VIN): GET https://api.nhtsa.gov/recalls/recallsByVehicle?make={make}&model={model}&modelYear={year}
- Record recall count and any open recalls

Record per VIN same structure as TOOL A.

**TOOL C: DAT consumer portal**
GET https://www.dat.de/gebrauchtfahrzeugwerte
- Check if page loads, if it requires login or CAPTCHA
- If it's a form: try POST with make/model/year/km params (inspect form fields from HTML)
- If blocked: document precisely why (login required, CAPTCHA, JS-only rendering)
- This tool is NOT VIN-based — test with BMW / X3 / 2022 / 50000km

Run script for all 3 VINs in test_vins.json. Print to stdout for each test:
"[TOOL] VIN {vin}: HTTP {status} — {fields_count} fields — {pass/fail}"

Save all results to tools/validation/results/vin_decode_results.json (create results/ dir if needed).

Use time.sleep(1) between tool calls. Import: requests, json, re, time, datetime. Do NOT import anything from src/cove/ or tools/scrapers/ — standalone only.
