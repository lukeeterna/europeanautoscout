```sql
    listing_id        VARCHAR PRIMARY KEY,   -- FK to cove_results.listing_id

    make              VARCHAR,               -- from cove_results
    model             VARCHAR,               -- from cove_results

    url               VARCHAR,               -- listing URL (constructed from listing_id)
    detail_url        VARCHAR,               -- direct detail page URL
    scraped_at        TIMESTAMP DEFAULT NOW(), -- when this record was created/enriched
    fuel_type         VARCHAR,               -- extracted from detail page (nullable)
    transmission      VARCHAR,               -- extracted from detail page (nullable)
    power_kw          INTEGER,               -- extracted from detail page (nullable)
    color             VARCHAR,               -- extracted from detail page (nullable)
    image_count       INTEGER DEFAULT 0     -- updated by enricher after image extraction
)
```

2. **VEHICLE_IMAGES_SCHEMA** constant — the CREATE TABLE IF NOT EXISTS SQL:

```sql
CREATE TABLE IF NOT EXISTS vehicle_images (
    id           INTEGER PRIMARY KEY,         -- auto-increment surrogate key
    listing_id   VARCHAR NOT NULL,            -- FK to vehicle_listings.listing_id
    image_url    VARCHAR NOT NULL,            -- full HTTPS URL from listing page
    image_type   VARCHAR DEFAULT 'listing',   -- 'listing' | 'exterior' | 'interior' | 'detail'
    downloaded   BOOLEAN DEFAULT FALSE,       -- True after local file saved
    local_path   VARCHAR                      -- relative path e.g. dossiers/images/{listing_id}/{n}.jpg
)
```

Note on `id`: DuckDB does not support AUTOINCREMENT. Use a SEQUENCE:
```sql
CREATE SEQUENCE IF NOT EXISTS vehicle_images_id_seq START 1;
```
Then in the table: `id INTEGER PRIMARY KEY DEFAULT nextval('vehicle_images_id_seq')`
