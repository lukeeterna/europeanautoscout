# docs/judge — canale di chiusura verso il giudice

Ogni sessione CC chiude scrivendo il proprio **BLOCCO-INCOLLA-AL-GIUDICE** in
`docs/judge/YYYYMMDD-HHMM-<slug>.md`, poi commit+push.

Il giudice non polla: Luke segnala "fatto". Finché il canale di lettura del giudice
non è attivo, il blocco si incolla **ANCHE in chat** (doppio canale).
