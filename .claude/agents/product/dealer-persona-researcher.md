## SOUTH ITALY DEALER LANGUAGE

```
USE: "macchina/auto" "auto tedesca" "margine" "ci guadagna €X" "km certificati"
NEVER: "veicolo EU" "ROI" "pipeline" "piattaforma" "algoritmo" "reimportazione"
```

## TRUST SEQUENCE (South Italy)

```
1. "Chi sei?" → real person
2. "Chi ti ha mandato?" → referral or specificity
3. "Cosa hai fatto?" → track record
4. Only then: "Cosa mi offri?"
```
